Вставь целиком в New Terminal в WinBox/WebFig. Создаст скрипт и задачу планировщика, которая будет дёргать хост каждые 5 минут.

    


    
    

      

        

        
      


      

        
        
        
      


      

        Скачай все три файла в одну папку (например, C:\ddns\), затем просто дважды кликни install-ddns-task.bat — сам запросит права администратора (UAC) и обойдёт блокировку запуска скриптов, ничего вручную включать не нужно.
      

      

        Спросит периодичность в минутах (Enter — 5, 0 — только при запуске компьютера, когда появится сеть, без повторов). Задать сразу без вопроса: install-ddns-task.bat -IntervalMinutes 10.
        Создаёт задачу в Планировщике (без видимого окна, вне зависимости от того, вошёл ли пользователь в систему) и сразу же один раз её запускает — не нужно первый раз срабатывания ждать или запускать вручную.
      

      

        Раз окна не видно, результат каждого запуска пишется в ddns-update.log рядом со скриптом — загляни туда, если хочешь убедиться, что обновления реально проходят, или если что-то не работает.
      


      

        Настроить вручную, без установщика
        

          
Программа
powershell.exe

          
Аргументы
-WindowStyle Hidden -ExecutionPolicy Bypass -File "C:\ddns-update.ps1"

          

            -ExecutionPolicy Bypass обязателен — Windows по умолчанию блокирует запуск любых .ps1 («выполнение сценариев отключено в этой системе»), это не связано со скриптом.
            -WindowStyle Hidden сам по себе не всегда убирает мигание полностью — для гарантии на вкладке «Общие» свойств задачи выбери «Выполнять вне зависимости от того, выполнен ли вход пользователя» вместо «только для вошедших пользователей».

Автообновление по расписанию (crontab -e):

      

        

        
      

      
Работает и на macOS, и на Linux, и на NAS с поддержкой cron — обновляет IP каждые 5 минут.

    


    
    

      

        Обычные домашние роутеры TP-Link (Archer и т.п.) и D-Link не поддерживают произвольный DDNS-сервер — только фиксированный список (No-IP, DynDNS, Comexe, TP-Link DDNS). Кастомный провайдер есть только у Omada (бизнес-линейка TP-Link).
      

      

        Рабочий вариант — запускать скрипт со вкладки Windows или macOS / Linux с любого постоянно включённого устройства в той же сети (ПК, NAS, Raspberry Pi). Внешний IP у него будет тот же, что и у роутера, так что результат идентичен.
      

      

        Если на роутере есть SSH и cron/init.d (актуально для некоторых D-Link и старых TP-Link с сторонней прошивкой вроде OpenWrt) — можно прописать команду с вкладки macOS / Linux прямо туда.
